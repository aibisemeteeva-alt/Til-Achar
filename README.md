## 🌟 Негизги мүмкүнчүлүктөр

1. **🏠 Башкы бет (Окуучулар үчүн)**:
   - Кичинекей ханзааданын накыл сөздөрү.
   - Топтолгон баллдардын, аткарылган тапшырмалардын жана окуган күндөрдүн статистикасы.
   - Чоң тестке чейинки күндөрдүн санак таймери.
   - 9 бөлүмдөн турган жол картасы (ачылуу даталары менен).

2. **📖 Тапшырмалар жана Окуу**:
   - 9 бөлүмдүн үзүндүлөрү жана тесттик суроолор.
   - Тест суроолору (варианттуу) жана ачык ой жүгүртүү тапшырмалары.
   - Жоопторду автоматтык түрдө сактоо жана балл эсептөө.

3. **🏆 Рейтинг**:
   - Командалык эсеп (Топтордун орточо жана жалпы упайлары).
   - Окуучулардын жеке рейтинги (🥇 🥈 🥉 медалдары менен).

4. **📋 Мугалимдердин панели (Окуучулардын жыйынтыктары)**:
   - Бардык окуучулардын активдүүлүгү, тапшырмалары жана упайлары.
   - Ар бир окуучунун жоопторун толук көрүү.
   - Оффлайн же кошумча тесттер үчүн кол менен балл киргизүү.

5. **💬 Көп каналдуу Чат**:
   - 🌍 Жалпы командалар аралык чат.
   - 👥 Ар бир команданын ички чаты.
   - 💬 Окуучу менен администрациянын жеке чаты.
   - Башка терезелерде жазылган билдирүүлөрдү реалдуу убакытта жаңылоо (`storage` окуясы аркылуу).

6. **⚙️ Администратор панели**:
   - Бөлүмдөрдүн жана тесттин ачылуу даталарын тандоо.
   - Окуучулардын командаларын өзгөртүү.
   - Тапшырмаларды JSON форматында түзөтүү жана сактоо.
